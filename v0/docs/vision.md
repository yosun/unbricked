# Vision (MVP)

**Unbricked is the Adobe-bricked, but dissected and examined.**
The unexamined brick is not worth editing.

## Core idea
- Everything is a **Space** you can enter.
- A “keyframe” is not the unit; it’s a doorway into a layered keyspace / worldspace.

## Two canonical 2D → 3D paths
1) **Segmentation-first**: image → segments/layers → 3D composition
2) **Holistic**: image → 3D without segmentation

## MVP UI thesis
- Start in **3D iso**.
- Show a translucent prism of slices (layers).
- Selecting a layer is spatial (hover/pick), not “find it in a panel”.
