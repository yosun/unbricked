# UI Philosophy (MVP)

## 3D-first
- Default viewport is 3D iso.
- 2D is a projection, not the master representation.

## Layers as slices
- A Space is represented as a rectangular prism.
- Slices are translucent planes.
- Objects/segments appear as outlines on slices.

## No form-first UX
- Avoid “ComfyUI graph UX”.
- We still have graph power; we don’t force graph navigation.
